# Chateau Blanc

Landing page institucional do Chateau Blanc, em Porto Alegre.

Site: https://mockup-chateau-blanc.vercel.app

Versão HTML independente, com as imagens incorporadas: [mockup-chateau-blanc.html](mockup-chateau-blanc.html)

## Desenvolvimento local

O site é estático. Abra `index.html` no navegador ou sirva esta pasta com um servidor HTTP local.

## Publicação

O projeto é publicado automaticamente pela Vercel a partir da branch `main`.
